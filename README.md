# floorplan-geom

单层住宅平面的精确几何校验库（TypeScript / Node，纯内存，无持久化、无依赖）。

## 坐标约定

- 地块局部坐标，单位 1/16 英寸，全部为 `[0, 10^6]` 内整数。
- 地块为矩形 `[0, W] x [0, D]`。
- 房间为沿墙中线画的简单多边形（可凹、可斜边、顺/逆时针均可、允许共线冗余顶点），不考虑墙厚。
- 窗为端点为整数点、长度为正、落在所属房间边界同一直线段上的线段（可跨冗余顶点）。

## API

```ts
import { FloorPlan, FloorPlanError } from 'floorplan-geom';

const fp = new FloorPlan(W, D);
fp.addRoom(id, polygon, windows?);    // polygon: {x,y}[], windows: {a:{x,y},b:{x,y}}[]
fp.updateRoom(id, polygon, windows?);
fp.removeRoom(id);
fp.exteriorSegments(id);              // => {a:{x,y}, b:{x,y}}[]，边界上不与任何其他
                                      //    房间边界重合的部分，相邻共线段已合并
```

每个被接受的操作完成后，以下性质全部成立；违反任一性质的操作被整体拒绝（状态完全不变）：

1. 房间多边形合法：面积非零、无零长边、非相邻边无公共点、相邻边仅共享端点。
2. 房间在地块内（贴边可以）。
3. 任意两个房间内部不相交（共墙 / 点接触 / 嵌入凹口均接受；重合、内部包含、交叉拒绝）。
4. 每扇窗与任何其他房间的边界、以及同房间其他窗，都没有正长度重合（双向检查：
   新增/移动房间压住别人的已有窗同样拒绝）。

## 错误类型

所有校验失败抛出 `FloorPlanError`，用 `code` 区分原因：

| code | 含义 |
| --- | --- |
| `INVALID_POLYGON` | 多边形不合法（性质 1） |
| `OUTSIDE_LOT` | 超出地块（性质 2） |
| `OVERLAP` | 与其他房间内部相交（性质 3），`otherRoomId` 为对方 id |
| `INVALID_WINDOW` | 窗端点非整数或零长 |
| `WINDOW_OFF_BOUNDARY` | 窗不在所属房间边界的同一直线段上 |
| `WINDOW_CONFLICT` | 窗与其他房间边界/其他窗正长度重合（性质 4），涉及其他房间时带 `otherRoomId` |
| `DUPLICATE_ROOM` / `ROOM_NOT_FOUND` | id 冲突 / 不存在 |

## 精确性

- 所有谓词（方向、在线段上、射线法、共线重合）都用整数运算，坐标 `<=10^6` 时
  中间结果 `<=2×10^12`，远在 double 精确整数范围 `2^53` 内。
- 房间重叠判定：双方耳切三角化后，三角形对用齐次有理数（BigInt）
  Sutherland–Hodgman 裁剪求交，交集有正面积才算重叠；仅接触（点/边）不算。
- 不使用任何浮点容差、栅格化或采样。

## 性能

房间级 + 三角形级包围盒剪枝。实测 1000 个各 64 顶点的房间紧密铺满一层，
逐个 `addRoom` 总耗时约 0.6 秒（限制 5 秒）。
